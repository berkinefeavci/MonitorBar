# PanelLight Privacy

PanelLight runs locally. It does not collect analytics, accounts, or telemetry and makes no automatic network request.

The **Hata bildir**, **Öneri gönder**, and **Güncellemeleri denetle** controls open GitHub in your browser only when pressed. GitHub then receives a normal browser request. No display settings or diagnostics are attached automatically.

Brightness, contrast, color, and schedule preferences stay on your Mac in the app's local settings. The app sends DDC/CI commands to connected displays and uses macOS display controls. It does not send those values to the developer.
